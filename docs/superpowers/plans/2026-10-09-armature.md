# Armature Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Armature v1, a single-pilot Git platform on Cloudflare Workers and Artifacts, far enough that the whole loop in the spec runs for real on camera by 2026-10-14.

**Architecture:** One TypeScript Worker with a plain `fetch` router, a `queue` consumer, a stateless MCP endpoint at `/mcp`, and a server-rendered cockpit. D1 holds the blueprint (vision and in-flight intents); landed chapters are exported into the project's Artifacts repo as the memoir. The Artifacts binding creates repos, forks and tokens and reads files; a POSIX script on the pilot's machine performs landings because the binding cannot push.

**Tech Stack:** TypeScript, Bun, Wrangler ≥ 4.145.0, Cloudflare Workers, Artifacts binding, D1, Queues with event subscriptions, Workers Builds, `agents` (`createMcpHandler`), `@modelcontextprotocol/server@2.0.0`, `zod`, `diff`, Vitest with `@cloudflare/vitest-plugin`.

**Spec:** `docs/superpowers/specs/2026-10-09-armature-design.md`

## Global Constraints

- Public repository under `omnypro`, MIT licence, `LICENSE` file present; commits are one line, plain, ending with a period, in Bryan's voice. No attribution trailers.
- Every file ends with a newline.
- No model runs in the Worker. The only automatic judgment is the deterministic overlap check.
- No third-party names (Marvel, Bandai, or any product) in code, README, prompts or the video. Role names are plain: challenger, builder, watcher.
- Single seat: one `PILOT_TOKEN` secret authenticates both the cockpit (cookie) and MCP (bearer).
- Artifacts namespace for the pilot: `armature`. Fork name: `<project>--<seq padded to 4>--<limb>`.
- Workers Builds from Artifacts only deploys `main`; project repos use `main`.
- The pilot's words are never rewritten by code: vision, intent title and body are stored and rendered verbatim (HTML-escaped).
- Chapters are append-only; a landed chapter is never re-exported with different content.
- Run `bun run test` before claiming anything passes; report its output.

## Review Focus

1. **A limb files a proposal whose `paths` is empty or has duplicates.** Expect: accepted, stored de-duplicated, no overlap poke for an empty list. Test added to Task 5.
2. **The pilot closes a challenge with questions still unanswered.** Expect: close succeeds, the intent page and the exported `exchanges.md` mark each one "unanswered". Tests in Tasks 4 and 6.
3. **A push event arrives twice for the same `(repo, after)`.** Expect: second delivery is a no-op, intent stays `landed` with the same `commit_ref`. Test in Task 12.
4. **A landing push whose head does not descend from the accepted commit.** Expect: recorded as a stray push on the intent; state unchanged. Test in Task 12.
5. **A request to `/mcp` or a cockpit action with a missing or wrong token.** Expect: 401 with no body leakage, nothing written. Test in Task 9.

```ts
// src/db/db.ts
import type { ArmatureEvent, Direction, Exchange, ExchangeKind, Fork, Intent, IntentState, Project, Proposal, ProposalState, Tag } from "../types";
import { newId, now } from "../types";

type Row = Record<string, unknown>;

const toProposal = (r: Row): Proposal => ({
  id: r.id as string, intent_id: r.intent_id as string, limb: r.limb as string,
  fork_repo: r.fork_repo as string, fork_remote: r.fork_remote as string,
  base_commit: r.base_commit as string, commit: r.commit_hash as string,
  paths: JSON.parse(r.paths as string) as string[], evidence: r.evidence as string,
  state: r.state as ProposalState, created_at: r.created_at as string, decided_at: (r.decided_at as string) ?? null,
});

const toExchange = (r: Row): Exchange => ({
  id: r.id as string, intent_id: r.intent_id as string, proposal_id: (r.proposal_id as string) ?? null,
  limb: (r.limb as string) ?? null, direction: r.direction as Direction, kind: r.kind as ExchangeKind,
  tag: (r.tag as Tag) ?? null, author: r.author as string, body: r.body as string,
  reply_to: (r.reply_to as string) ?? null,
  taken: r.taken === null || r.taken === undefined ? null : r.taken === 1,
  private: r.private === 1,
  created_at: r.created_at as string,
});

export class Db {
  constructor(private readonly d1: D1Database) {}

  // Projects
  async createProject(p: { slug: string; namespace: string; repo: string; remote: string }): Promise<Project> {
    const project: Project = { id: newId(), slug: p.slug, vision: "", namespace: p.namespace, repo: p.repo, remote: p.remote, subscription_id: null, created_at: now() };
    await this.d1.prepare("INSERT INTO projects (id, slug, vision, namespace, repo, remote, subscription_id, created_at) VALUES (?,?,?,?,?,?,?,?)")
      .bind(project.id, project.slug, project.vision, project.namespace, project.repo, project.remote, null, project.created_at).run();
    return project;
  }
  getProjectBySlug(slug: string): Promise<Project | null> {
    return this.d1.prepare("SELECT * FROM projects WHERE slug = ?").bind(slug).first<Project>();
  }
  getProject(id: string): Promise<Project | null> {
    return this.d1.prepare("SELECT * FROM projects WHERE id = ?").bind(id).first<Project>();
  }
  getProjectByRepo(repo: string): Promise<Project | null> {
    return this.d1.prepare("SELECT * FROM projects WHERE repo = ?").bind(repo).first<Project>();
  }
  async listProjects(): Promise<Project[]> {
    return (await this.d1.prepare("SELECT * FROM projects ORDER BY created_at").all<Project>()).results;
  }
  async setVision(id: string, vision: string): Promise<void> {
    await this.d1.prepare("UPDATE projects SET vision = ? WHERE id = ?").bind(vision, id).run();
  }
  async setProjectSubscription(id: string, subscriptionId: string | null): Promise<void> {
    await this.d1.prepare("UPDATE projects SET subscription_id = ? WHERE id = ?").bind(subscriptionId, id).run();
  }

  // Intents
  async createIntent(projectId: string, title: string, body: string): Promise<Intent> {
    const next = await this.d1.prepare("SELECT COALESCE(MAX(seq), 0) + 1 AS seq FROM intents WHERE project_id = ?").bind(projectId).first<{ seq: number }>();
    const intent: Intent = {
      id: newId(), project_id: projectId, seq: next?.seq ?? 1, title, body, state: "open",
      accepted_proposal_id: null, commit_ref: null, created_at: now(), closed_at: null, accepted_at: null, landed_at: null,
    };
    await this.d1.prepare("INSERT INTO intents (id, project_id, seq, title, body, state, created_at) VALUES (?,?,?,?,?,?,?)")
```

```ts
// src/model/intent.ts
import type { IntentState, ProposalState } from "../types";

const TRANSITIONS: Record<IntentState, readonly IntentState[]> = {
  open: ["closed", "shelved"],
  closed: ["accepted", "shelved"],
  accepted: ["landed"],
  landed: [],
  shelved: [],
};

export class TransitionError extends Error {
  constructor(from: IntentState, to: IntentState) {
    super(`intent cannot move ${from} -> ${to}`);
    this.name = "TransitionError";
  }
}

export const canTransition = (from: IntentState, to: IntentState): boolean => TRANSITIONS[from].includes(to);

export const assertTransition = (from: IntentState, to: IntentState): void => {
  if (!canTransition(from, to)) throw new TransitionError(from, to);
};

export const canDecideProposal = (state: ProposalState): boolean => state === "open";
```

```ts
// src/model/exchange.ts
import type { Direction, Exchange, ExchangeKind } from "../types";

export const directionFor = (kind: ExchangeKind, replyTo?: Exchange): Direction => {
  switch (kind) {
    case "question":
    case "poke":
      return "to_pilot";
    case "challenge":
    case "steer":
      return "to_crew";
    case "reply":
      if (!replyTo) throw new Error("reply needs reply_to");
      return replyTo.direction === "to_pilot" ? "to_crew" : "to_pilot";
  }
};

const repliesTo = (exchanges: Exchange[], id: string): Exchange[] => exchanges.filter((e) => e.kind === "reply" && e.reply_to === id);

export const unansweredQuestions = (exchanges: Exchange[]): Exchange[] =>
  exchanges.filter((e) => e.kind === "question" && !repliesTo(exchanges, e.id).some((r) => r.author === "pilot"));

export const blockingChallenges = (exchanges: Exchange[], proposalId: string): Exchange[] =>
  exchanges.filter(
    (e) => e.kind === "challenge" && e.proposal_id === proposalId && !repliesTo(exchanges, e.id).some((r) => r.author !== "pilot"),
  );

export const openPokes = (exchanges: Exchange[]): Exchange[] => exchanges.filter((e) => e.kind === "poke" && e.taken === null);

export const withheldIds = (exchanges: Exchange[]): Set<string> => {
  const withheld = new Set(exchanges.filter((e) => e.private).map((e) => e.id));
  let grew = true;
  while (grew) {
    grew = false;
    for (const e of exchanges) {
      if (e.reply_to && withheld.has(e.reply_to) && !withheld.has(e.id)) {
        withheld.add(e.id);
        grew = true;
      }
    }
  }
  return withheld;
};
```

```ts
// src/model/overlap.ts
export interface Overlap { a: string; b: string; paths: string[] }
interface WithPaths { id: string; paths: string[] }

export const findOverlaps = (candidate: WithPaths, others: WithPaths[]): Overlap[] => {
  const mine = new Set(candidate.paths);
  const out: Overlap[] = [];
  for (const other of others) {
    if (other.id === candidate.id) continue;
    const shared = Array.from(new Set(other.paths)).filter((p) => mine.has(p)).sort();
    if (shared.length > 0) out.push({ a: candidate.id, b: other.id, paths: shared });
  }
  return out;
};

export const overlapPokeBody = (overlap: Overlap, limbA: string, limbB: string): string =>
  `${limbA} and ${limbB} both touch ${overlap.paths.join(", ")}; one of these proposals will need a rebase.`;
```

```ts
// src/model/memoir.ts
import type { Exchange, Fork, Intent, Project, Proposal } from "../types";
import { withheldIds } from "./exchange";

export interface ChapterInput { project: Project; intent: Intent; exchanges: Exchange[]; proposals: Proposal[]; forks: Fork[] }
export interface ChapterFiles { dir: string; files: Record<"intent.md" | "exchanges.md" | "proposals.md", string>; blueprint: string }

export const chapterDir = (seq: number, title: string): string => {
  const slug = title.toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/^-+|-+$/g, "");
  return `${String(seq).padStart(4, "0")}-${slug}`;
};

const describe = (e: Exchange): string => {
  const kind = e.kind === "poke" && e.tag ? `poke (${e.tag})` : e.kind;
  const to = e.direction === "to_pilot" ? "to the pilot" : e.limb ? `to ${e.limb}` : "to the crew";
  return `${kind}, from ${e.author}, ${to}`;
};

const renderIntent = (i: Intent): string =>
  [
    "---", `seq: ${i.seq}`, `title: ${i.title}`, `state: ${i.state}`, `created: ${i.created_at}`,
    `closed: ${i.closed_at ?? ""}`, `accepted: ${i.accepted_at ?? ""}`, `landed: ${i.landed_at ?? ""}`, `commit: ${i.commit_ref ?? ""}`,
    "---", "", `# ${i.title}`, "", i.body, "",
  ].join("\n");

const renderExchanges = (all: Exchange[]): string => {
  const withheld = withheldIds(all);
  const visible = all.filter((e) => !withheld.has(e.id));
  const replies = (id: string) => visible.filter((r) => r.kind === "reply" && r.reply_to === id);
  const roots = visible.filter((e) => e.kind !== "reply");
  const parts: string[] = ["# Exchanges", ""];
  for (const root of roots) {
    parts.push(`## ${describe(root)}`, "", root.body, "");
    const rs = replies(root.id);
    if (root.kind === "question" && !rs.some((r) => r.author === "pilot")) parts.push("> unanswered", "");
    if (root.kind === "poke") parts.push(root.taken === true ? "> taken by the pilot" : root.taken === false ? "> dismissed by the pilot" : "> not decided", "");
    for (const r of rs) {
      parts.push(`> ${r.author} replied: ${r.body}`, "");
      for (const rr of replies(r.id)) parts.push(`> > ${rr.author} replied: ${rr.body}`, "");
    }
  }
  if (withheld.size > 0) parts.push(`${withheld.size} exchange${withheld.size === 1 ? "" : "s"} withheld by the pilot.`, "");
  return parts.join("\n");
};

const renderProposals = (proposals: Proposal[], forks: Fork[]): string => {
  const parts: string[] = ["# Proposals", ""];
  for (const p of proposals) {
    const fork = forks.find((f) => f.fork_repo === p.fork_repo);
    parts.push(`## ${p.limb}, ${p.commit.slice(0, 12)}, ${p.state}`, "");
    parts.push(`Fork: ${p.fork_repo} (base ${p.base_commit.slice(0, 12)}${fork?.last_push_at ? `, last push ${fork.last_push_at}` : ""})`);
    parts.push(`Paths: ${p.paths.join(", ")}`, "", "Evidence:", "", p.evidence, "");
  }
  if (proposals.length === 0) parts.push("No proposals were filed.", "");
  return parts.join("\n");
};

export const renderChapter = (input: ChapterInput): ChapterFiles => ({
  dir: chapterDir(input.intent.seq, input.intent.title),
  files: {
    "intent.md": renderIntent(input.intent),
    "exchanges.md": renderExchanges(input.exchanges),
    "proposals.md": renderProposals(input.proposals, input.forks),
  },
  blueprint: `# Blueprint\n\n${input.project.vision}\n`,
});
```

```ts
export const renderUnified = (path: string, before: string | null, after: string | null): string => {
  if (before === after) return `(no changes in ${path})\n`;
  const oldName = before === null ? "/dev/null" : `a/${path}`;

};
```

```ts
// src/artifacts.ts
export interface RepoRef { name: string; remote: string; defaultBranch: string }

export interface ArtifactsPort {
  create(name: string): Promise<RepoRef>;
  fork(source: string, target: string): Promise<RepoRef>;
  createToken(repo: string, scope: "read" | "write", ttlSeconds: number): Promise<{ plaintext: string; expiresAt: string }>;
  readFile(repo: string, ref: string, path: string): Promise<string | null>;
  headCommit(repo: string, ref: string): Promise<string | null>;
  isAncestor(repo: string, ancestor: string, head: string): Promise<boolean>;
}

// Field names on ArtifactsCommitMetadata, read from worker-configuration.d.ts
// in Task 1 step 8. Change these two constants if the generated type differs.
const COMMIT_HASH_FIELD = "hash";

const hashOf = (commit: unknown): string => (commit as Record<string, string>)[COMMIT_HASH_FIELD];

export const realArtifacts = (artifacts: Artifacts): ArtifactsPort => ({
  async create(name) {
    const created = await artifacts.create(name, { setDefaultBranch: "main" });
    return { name: created.name, remote: created.remote, defaultBranch: created.defaultBranch };
  },
  async fork(source, target) {
    using repo = await artifacts.get(source);
    const forked = await repo.fork(target, { defaultBranchOnly: true });
    return { name: forked.name, remote: forked.remote, defaultBranch: forked.defaultBranch };
  },
  async createToken(repoName, scope, ttlSeconds) {
    using repo = await artifacts.get(repoName);
    const token = await repo.createToken(scope, ttlSeconds);
    return { plaintext: token.plaintext, expiresAt: String(token.expiresAt) };
  },
  async readFile(repoName, ref, path) {
    using repo = await artifacts.get(repoName);
    const blob = await repo.readFile({ ref, path });
    return blob === null ? null : await blob.text();
  },
  async headCommit(repoName, ref) {
    using repo = await artifacts.get(repoName);
    const log = await repo.log({ ref, limit: 1 });
    return log.length === 0 ? null : hashOf(log[0]);
  },
  async isAncestor(repoName, ancestor, head) {
    if (ancestor === head) return true;
    using repo = await artifacts.get(repoName);
    const log = await repo.log({ ref: head, limit: 1000 });
    return log.some((c) => hashOf(c) === ancestor);
  },
});
```

```ts
// src/auth.ts
import type { Env } from "./env";

export const COOKIE_NAME = "armature_seat";

const equal = (a: string, b: string): boolean => {
  const enc = new TextEncoder();
  const x = enc.encode(a);
  const y = enc.encode(b);
  if (x.byteLength !== y.byteLength) return false;
  return crypto.subtle.timingSafeEqual(x, y);
};

const presented = (request: Request): string | null => {
  const auth = request.headers.get("authorization");
  if (auth?.startsWith("Bearer ")) return auth.slice(7).trim();
  const cookie = request.headers.get("cookie") ?? "";
  for (const part of cookie.split(";")) {
    const [k, ...rest] = part.trim().split("=");
    if (k === COOKIE_NAME) return rest.join("=");
  }
  return null;
};

export const isPilot = (request: Request, env: Env): boolean => {
  const token = presented(request);
  return token !== null && env.PILOT_TOKEN.length > 0 && equal(token, env.PILOT_TOKEN);
};

export const seatCookie = (token: string): string =>
  `${COOKIE_NAME}=${token}; Path=/; HttpOnly; Secure; SameSite=Strict; Max-Age=2592000`;
```

```ts
// src/service.ts
import type { ArtifactsPort } from "./artifacts";
import type { Db } from "./db/db";
import { renderUnified } from "./model/diff";
import { blockingChallenges, directionFor, openPokes, unansweredQuestions } from "./model/exchange";
import { assertTransition, canDecideProposal } from "./model/intent";
import { type ChapterFiles, chapterDir, renderChapter } from "./model/memoir";
import { type Overlap, findOverlaps, overlapPokeBody } from "./model/overlap";
import type { ArmatureEvent, Exchange, ExchangeKind, Fork, Intent, Project, Proposal, Tag } from "./types";
import { now } from "./types";

export class ServiceError extends Error {
  constructor(message: string, readonly status = 409) { super(message); this.name = "ServiceError"; }
}

export interface FileExchange { intentId: string; kind: ExchangeKind; body: string; author: string; tag?: Tag; proposalId?: string; replyTo?: string; limb?: string; private?: boolean }
export interface IntentRow { intent: Intent; unanswered: number; openPokes: number; limbs: string[]; openProposals: number; overlaps: number }
export interface ProjectView { project: Project; doctrine: string | null; intents: IntentRow[]; chapters: string[] }
export interface ProposalView { proposal: Proposal; blocking: Exchange[]; overlaps: Overlap[]; diffs: { path: string; diff: string }[] }
export interface IntentView { project: Project; intent: Intent; exchanges: Exchange[]; forks: Fork[]; proposals: ProposalView[]; unanswered: Exchange[]; openPokes: Exchange[] }

const DOCTRINE_PATH = "ARMATURE.md";
const TOKEN_TTL_SECONDS = 60 * 60 * 24 * 7;

export class Armature {
  constructor(
    private readonly db: Db,
    private readonly artifacts: ArtifactsPort,
    private readonly subscribe: (repo: string) => Promise<string | null>,
    private readonly namespace: string,
  ) {}

  private async intentOr404(id: string): Promise<Intent> {
    const intent = await this.db.getIntent(id);
    if (!intent) throw new ServiceError("no such intent", 404);
    return intent;
  }

  async createProject(slug: string): Promise<Project> {
    if (!/^[a-z0-9][a-z0-9._-]{1,62}$/.test(slug)) throw new ServiceError("slug must be lowercase letters, digits, dots, dashes", 400);
    const repo = await this.artifacts.create(slug);
    const project = await this.db.createProject({ slug, namespace: this.namespace, repo: repo.name, remote: repo.remote });
    const subscriptionId = await this.subscribe(repo.name);
    if (subscriptionId) await this.db.setProjectSubscription(project.id, subscriptionId);
    await this.db.recordEvent(project.id, "project.created", project.id);
    return { ...project, subscription_id: subscriptionId };
  }

  async setVision(projectId: string, vision: string): Promise<void> {
    await this.db.setVision(projectId, vision);
    await this.db.recordEvent(projectId, "vision.edited", projectId);
  }

  async createIntent(projectId: string, title: string, body: string): Promise<Intent> {
    if (!title.trim()) throw new ServiceError("an intent needs a title", 400);
    const intent = await this.db.createIntent(projectId, title.trim(), body);
    await this.db.recordEvent(projectId, "intent.created", intent.id);
    return intent;
  }

  async fileExchange(input: FileExchange): Promise<Exchange> {
    const intent = await this.intentOr404(input.intentId);
    if (!input.body.trim()) throw new ServiceError("an exchange needs a body", 400);
    const replyTo = input.replyTo ? await this.db.getExchange(input.replyTo) : null;
    if (input.kind === "reply" && !replyTo) throw new ServiceError("reply_to does not exist", 400);
    if (input.kind === "poke" && !input.tag) throw new ServiceError("a poke needs a tag", 400);
    const exchange = await this.db.createExchange({
      intent_id: intent.id, proposal_id: input.proposalId ?? replyTo?.proposal_id ?? null, limb: input.limb ?? null,
      direction: directionFor(input.kind, replyTo ?? undefined), kind: input.kind, tag: input.kind === "poke" ? input.tag! : null,
      author: input.author, body: input.body, reply_to: replyTo?.id ?? null, taken: null, private: input.private ?? false,
    });
    await this.db.recordEvent(intent.project_id, "exchange.filed", exchange.id, `${exchange.kind}:${exchange.author}`);
    return exchange;
  }

  async setTaken(exchangeId: string, taken: boolean, reason?: string): Promise<void> {
    const poke = await this.db.getExchange(exchangeId);
    if (!poke || poke.kind !== "poke") throw new ServiceError("not a poke", 400);
    await this.db.setTaken(poke.id, taken);
    if (reason?.trim()) await this.fileExchange({ intentId: poke.intent_id, kind: "reply", body: reason, author: "pilot", replyTo: poke.id });
    const intent = await this.intentOr404(poke.intent_id);
    await this.db.recordEvent(intent.project_id, taken ? "poke.taken" : "poke.dismissed", poke.id);
  }

  async setPrivate(exchangeId: string, isPrivate: boolean): Promise<void> {
    const exchange = await this.db.getExchange(exchangeId);
    if (!exchange) throw new ServiceError("no such exchange", 404);
    const intent = await this.intentOr404(exchange.intent_id);
    if (intent.state === "landed") throw new ServiceError("the chapter has landed; the memoir is append-only");
    await this.db.setPrivate(exchange.id, isPrivate);
  }

  async closeChallenge(intentId: string): Promise<Intent> {
    const intent = await this.intentOr404(intentId);
    assertTransition(intent.state, "closed");
    await this.db.updateIntent(intent.id, { state: "closed", closed_at: now() });
    await this.db.recordEvent(intent.project_id, "intent.closed", intent.id);
    return (await this.db.getIntent(intent.id))!;
  }

  async shelve(intentId: string): Promise<Intent> {
    const intent = await this.intentOr404(intentId);
    assertTransition(intent.state, "shelved");
    await this.db.updateIntent(intent.id, { state: "shelved" });
    await this.db.recordEvent(intent.project_id, "intent.shelved", intent.id);
    return (await this.db.getIntent(intent.id))!;
  }

  async requestFork(intentId: string, limb: string): Promise<{ fork: Fork; token: string }> {
    const intent = await this.intentOr404(intentId);
    if (intent.state !== "closed") throw new ServiceError(`the challenge is ${intent.state}; a fork needs it closed`);
    if (!/^[a-z0-9][a-z0-9-]{0,39}$/.test(limb)) throw new ServiceError("limb names are lowercase letters, digits, dashes", 400);
    const project = (await this.db.getProject(intent.project_id))!;
    const target = `${project.repo}--${String(intent.seq).padStart(4, "0")}--${limb}`;
    const existing = await this.db.getForkByRepo(target);
    if (existing) {
      const token = await this.artifacts.createToken(target, "write", TOKEN_TTL_SECONDS);
      return { fork: existing, token: token.plaintext };
    }
    const base = await this.artifacts.headCommit(project.repo, "main");
    if (!base) throw new ServiceError("the project repo has no main yet; push it first");
    const forked = await this.artifacts.fork(project.repo, target);
    const subscriptionId = await this.subscribe(target);
    const fork = await this.db.createFork({ intent_id: intent.id, limb, fork_repo: forked.name, fork_remote: forked.remote, base_commit: base, subscription_id: subscriptionId });
    const token = await this.artifacts.createToken(target, "write", TOKEN_TTL_SECONDS);
    await this.db.recordEvent(project.id, "fork.created", fork.id, limb);
    return { fork, token: token.plaintext };
  }

  async fileProposal(input: { intentId: string; limb: string; commit: string; paths: string[]; evidence: string }): Promise<{ proposal: Proposal; overlaps: Overlap[] }> {
    const intent = await this.intentOr404(input.intentId);
    if (intent.state !== "closed") throw new ServiceError(`the intent is ${intent.state}; proposals need it closed`);
    const forks = await this.db.listForks(intent.id);
    const fork = forks.find((f) => f.limb === input.limb);
    if (!fork) throw new ServiceError("this limb has no fork on this intent", 400);
    if (!/^[0-9a-f]{40}$/.test(input.commit)) throw new ServiceError("commit must be a 40-char sha", 400);
    const previous = (await this.db.listProposals(intent.id)).filter((p) => p.limb === input.limb && p.state === "open");
    for (const p of previous) await this.db.setProposalState(p.id, "superseded");
    const proposal = await this.db.createProposal({
      intent_id: intent.id, limb: input.limb, fork_repo: fork.fork_repo, fork_remote: fork.fork_remote,
      base_commit: fork.base_commit, commit: input.commit, paths: input.paths, evidence: input.evidence,
    });
    const others = (await this.db.listOpenProposalsForProject(intent.project_id)).filter((p) => p.id !== proposal.id);
    const overlaps = findOverlaps(proposal, others);
    for (const overlap of overlaps) {
      const other = others.find((p) => p.id === overlap.b)!;
      await this.fileExchange({ intentId: intent.id, kind: "poke", tag: "heads_up", author: "armature", proposalId: proposal.id, body: overlapPokeBody(overlap, proposal.limb, other.limb) });
      if (other.intent_id !== intent.id) {
        await this.fileExchange({ intentId: other.intent_id, kind: "poke", tag: "heads_up", author: "armature", proposalId: other.id, body: overlapPokeBody(overlap, proposal.limb, other.limb) });
      }
    }
    await this.db.recordEvent(intent.project_id, "proposal.filed", proposal.id, input.limb);
    return { proposal, overlaps };
  }

  async accept(intentId: string, proposalId: string): Promise<Intent> {
    const intent = await this.intentOr404(intentId);
    assertTransition(intent.state, "accepted");
    const proposal = await this.db.getProposal(proposalId);
    if (!proposal || proposal.intent_id !== intent.id) throw new ServiceError("no such proposal on this intent", 404);
    if (!canDecideProposal(proposal.state)) throw new ServiceError(`proposal is ${proposal.state}`);
    const exchanges = await this.db.listExchanges(intent.id);
    const blocking = blockingChallenges(exchanges, proposal.id);
    if (blocking.length > 0) throw new ServiceError(`${blocking.length} challenge${blocking.length === 1 ? "" : "s"} still need an answer from ${proposal.limb}`);
    await this.db.setProposalState(proposal.id, "accepted");
    for (const p of await this.db.listProposals(intent.id)) if (p.id !== proposal.id && p.state === "open") await this.db.setProposalState(p.id, "superseded");
    await this.db.updateIntent(intent.id, { state: "accepted", accepted_proposal_id: proposal.id, accepted_at: now() });
    await this.db.recordEvent(intent.project_id, "proposal.accepted", proposal.id);
    return (await this.db.getIntent(intent.id))!;
  }

  async reject(proposalId: string): Promise<void> {
    const proposal = await this.db.getProposal(proposalId);
    if (!proposal) throw new ServiceError("no such proposal", 404);
    if (!canDecideProposal(proposal.state)) throw new ServiceError(`proposal is ${proposal.state}`);
    await this.db.setProposalState(proposal.id, "rejected");
    const intent = await this.intentOr404(proposal.intent_id);
    await this.db.recordEvent(intent.project_id, "proposal.rejected", proposal.id);
  }

  async markLanded(repo: string, after: string, pushed: { id: string; parents: string[] }[], truncated: boolean): Promise<"landed" | "stray" | "ignored"> {
    if (!(await this.db.markPushSeen(repo, after))) return "ignored";
    const project = await this.db.getProjectByRepo(repo);
    if (!project) return "ignored";
    const accepted = await this.db.listIntents(project.id, "accepted");
    for (const intent of accepted) {
      const proposal = intent.accepted_proposal_id ? await this.db.getProposal(intent.accepted_proposal_id) : null;
      if (!proposal) continue;
      const inPayload = pushed.some((c) => c.id === proposal.commit || c.parents.includes(proposal.commit));
      const descends = inPayload || (truncated && (await this.artifacts.isAncestor(repo, proposal.commit, after)));
      if (!descends) continue;
      await this.db.updateIntent(intent.id, { state: "landed", commit_ref: after, landed_at: now() });
      await this.db.recordEvent(project.id, "intent.landed", intent.id, after);
      return "landed";
    }
    await this.db.recordEvent(project.id, "push.stray", after, repo);
    return "stray";
  }

  async exportChapter(intentId: string): Promise<ChapterFiles> {
    const intent = await this.intentOr404(intentId);
    const project = (await this.db.getProject(intent.project_id))!;
    return renderChapter({ project, intent, exchanges: await this.db.listExchanges(intent.id), proposals: await this.db.listProposals(intent.id), forks: await this.db.listForks(intent.id) });
  }

  async projectView(slug: string): Promise<ProjectView | null> {
    const project = await this.db.getProjectBySlug(slug);
    if (!project) return null;
    const doctrine = await this.artifacts.readFile(project.repo, "main", DOCTRINE_PATH);
    const openProposals = await this.db.listOpenProposalsForProject(project.id);
    const intents: IntentRow[] = [];
    for (const intent of await this.db.listIntents(project.id)) {
      const exchanges = await this.db.listExchanges(intent.id);
      const forks = await this.db.listForks(intent.id);
      const mine = openProposals.filter((p) => p.intent_id === intent.id);
      const overlaps = mine.reduce((n, p) => n + findOverlaps(p, openProposals).length, 0);
      intents.push({ intent, unanswered: unansweredQuestions(exchanges).length, openPokes: openPokes(exchanges).length, limbs: forks.map((f) => f.limb), openProposals: mine.length, overlaps });
    }
    const chapters = intents.filter((r) => r.intent.state === "landed").map((r) => chapterDir(r.intent.seq, r.intent.title));
    return { project, doctrine, intents, chapters };
  }

  async intentView(intentId: string): Promise<IntentView | null> {
    const intent = await this.db.getIntent(intentId);
    if (!intent) return null;
    const project = (await this.db.getProject(intent.project_id))!;
    const exchanges = await this.db.listExchanges(intent.id);
    const forks = await this.db.listForks(intent.id);
    const openAll = await this.db.listOpenProposalsForProject(project.id);
    const proposals: ProposalView[] = [];
    for (const proposal of await this.db.listProposals(intent.id)) {
      const diffs: { path: string; diff: string }[] = [];
      for (const path of proposal.paths) {
        const before = await this.artifacts.readFile(proposal.fork_repo, proposal.base_commit, path);
        const after = await this.artifacts.readFile(proposal.fork_repo, proposal.commit, path);
        diffs.push({ path, diff: renderUnified(path, before, after) });
      }
      proposals.push({ proposal, blocking: blockingChallenges(exchanges, proposal.id), overlaps: proposal.state === "open" ? findOverlaps(proposal, openAll) : [], diffs });
    }
    return { project, intent, exchanges, forks, proposals, unanswered: unansweredQuestions(exchanges), openPokes: openPokes(exchanges) };
  }

  async changesSince(slug: string, cursor: number): Promise<ArmatureEvent[]> {
    const project = await this.db.getProjectBySlug(slug);
    if (!project) throw new ServiceError("no such project", 404);
    return this.db.eventsSince(project.id, cursor);
  }
}
```

```ts
import { isPilot, seatCookie } from "./auth";
import { actions } from "./cockpit/actions";
import { page, redirect } from "./cockpit/html";
import { intentPage, loginPage, projectPage, projectsPage } from "./cockpit/pages";
import type { Env } from "./env";
import { type Armature, ServiceError } from "./service";
import { TransitionError } from "./model/intent";

type Handler = (armature: Armature, params: string[], request: Request, env: Env) => Promise<Response>;
interface Route { method: string; pattern: RegExp; handler: Handler; open?: boolean }

const html = (title: string, body: string) => page(title, body);
const json = (data: unknown, status = 200) => Response.json(data, { status });

const routes: Route[] = [
  { method: "GET", pattern: /^\/health$/, open: true, handler: async () => json({ ok: true }) },
  { method: "GET", pattern: /^\/login$/, open: true, handler: async () => new Response(loginPage(), { headers: { "content-type": "text/html;charset=utf-8" } }) },
  { method: "POST", pattern: /^\/login$/, open: true, handler: async (_a, _p, request, env) => {
    const token = String((await request.formData()).get("token") ?? "");
    const probe = new Request(request.url, { headers: { authorization: `Bearer ${token}` } });
    return isPilot(probe, env) ? redirect("/", { "set-cookie": seatCookie(token) }) : new Response("Wrong token", { status: 401 });
  } },
  { method: "GET", pattern: /^\/$/, handler: async (a) => html("Projects", projectsPage(await a.listProjects())) },
  { method: "POST", pattern: /^\/projects$/, handler: async (a, _p, request) => {
    const project = await a.createProject(String((await request.formData()).get("slug") ?? "").trim());
    return redirect(`/p/${project.slug}`);
  } },
  { method: "GET", pattern: /^\/p\/([^/]+)$/, handler: async (a, [slug]) => { const v = await a.projectView(slug); return v ? html(slug, projectPage(v)) : new Response("Not found", { status: 404 }); } },
  { method: "POST", pattern: /^\/p\/([^/]+)\/vision$/, handler: async (a, [slug], request) => actions.vision(a, slug, await request.formData()) },
  { method: "POST", pattern: /^\/p\/([^/]+)\/intents$/, handler: async (a, [slug], request) => actions.intent(a, slug, await request.formData()) },
  { method: "GET", pattern: /^\/i\/([^/]+)$/, handler: async (a, [id]) => { const v = await a.intentView(id); return v ? html(v.intent.title, intentPage(v)) : new Response("Not found", { status: 404 }); } },
  { method: "POST", pattern: /^\/i\/([^/]+)\/reply$/, handler: async (a, [id], r) => actions.reply(a, id, await r.formData()) },
  { method: "POST", pattern: /^\/i\/([^/]+)\/verdict$/, handler: async (a, [id], r) => actions.verdict(a, id, await r.formData()) },
  { method: "POST", pattern: /^\/i\/([^/]+)\/challenge$/, handler: async (a, [id], r) => actions.challenge(a, id, await r.formData()) },
  { method: "POST", pattern: /^\/i\/([^/]+)\/steer$/, handler: async (a, [id], r) => actions.steer(a, id, await r.formData()) },
  { method: "POST", pattern: /^\/i\/([^/]+)\/private$/, handler: async (a, [id], r) => actions.privacy(a, id, await r.formData()) },
  { method: "POST", pattern: /^\/i\/([^/]+)\/close$/, handler: async (a, [id]) => actions.close(a, id) },
  { method: "POST", pattern: /^\/i\/([^/]+)\/shelve$/, handler: async (a, [id]) => actions.shelve(a, id) },
  { method: "POST", pattern: /^\/i\/([^/]+)\/accept$/, handler: async (a, [id], r) => actions.accept(a, id, await r.formData()) },
  { method: "POST", pattern: /^\/i\/([^/]+)\/reject$/, handler: async (a, [id], r) => actions.reject(a, id, await r.formData()) },
  { method: "GET", pattern: /^\/api\/intent\/([^/]+)$/, handler: async (a, [id]) => { const v = await a.intentView(id); return v ? json(v) : json({ error: "no such intent" }, 404); } },
  { method: "GET", pattern: /^\/api\/intent\/([^/]+)\/export$/, handler: async (a, [id]) => json(await a.exportChapter(id)) },
];

export const route = async (request: Request, env: Env, armature: Armature): Promise<Response> => {
  const url = new URL(request.url);
  for (const r of routes) {
    if (r.method !== request.method) continue;
    const m = url.pathname.match(r.pattern);
    if (!m) continue;
    if (!r.open && !isPilot(request, env)) {
      return url.pathname.startsWith("/api/") || request.method !== "GET" ? new Response(null, { status: 401 }) : redirect("/login");
    }
    try {
      return await r.handler(armature, m.slice(1), request, env);
    } catch (error) {
      if (error instanceof ServiceError) return page("Refused", `<h1>Refused</h1><p>${error.message}</p><p><a href="javascript:history.back()">back</a></p>`, error.status);
      if (error instanceof TransitionError) return page("Refused", `<h1>Refused</h1><p>${error.message}</p>`, 409);
      throw error;
    }
  }
  return new Response("Not found", { status: 404 });
};
```

```ts
import type { Env } from "./env";

export const subscribeRepoPushes = async (env: Env, repo: string, fetchImpl: typeof fetch = fetch): Promise<string | null> => {
  if (!env.CF_API_TOKEN || !env.EVENTS_QUEUE_ID) return null;
  try {
    const res = await fetchImpl(`https://api.cloudflare.com/client/v4/accounts/${env.CF_ACCOUNT_ID}/event_subscriptions/subscriptions`, {
      method: "POST",
      headers: { authorization: `Bearer ${env.CF_API_TOKEN}`, "content-type": "application/json" },
      body: JSON.stringify({
        name: `armature:${repo}`, enabled: true, events: ["pushed"],
        source: { type: "artifacts.repo", namespace: env.ARTIFACTS_NAMESPACE, repo_name: repo },
        destination: { type: "queues.queue", queue_id: env.EVENTS_QUEUE_ID },
      }),
    });
    const body = (await res.json()) as { success?: boolean; result?: { id?: string }; errors?: { message: string }[] };
    if (!res.ok || !body.success || !body.result?.id) {
      console.warn("subscription failed", repo, res.status, JSON.stringify(body.errors ?? []));
      return null;
    }
    return body.result.id;
  } catch (error) {
    console.warn("subscription errored", repo, error instanceof Error ? error.message : String(error));
    return null;
  }
};
```

```sh
#!/bin/sh
# bin/land <project-slug> <intent-id>
# Lands an accepted proposal: fetch its commit from the fork, export the chapter
# from the cockpit, commit the memoir on top, push main. The push event marks
# the intent landed. Needs git, curl, jq, and:
#   ARMATURE_URL, ARMATURE_TOKEN, ARMATURE_FORK_TOKEN, ARMATURE_PROJECT_TOKEN
#   ARMATURE_MIRROR (optional GitHub remote, pushed after the project repo)
set -eu

slug="${1:?project slug}"
intent="${2:?intent id}"
: "${ARMATURE_URL:?}" "${ARMATURE_TOKEN:?}" "${ARMATURE_FORK_TOKEN:?}" "${ARMATURE_PROJECT_TOKEN:?}"

api() { curl -fsS -H "Authorization: Bearer $ARMATURE_TOKEN" "$ARMATURE_URL$1"; }

record="$(api "/api/intent/$intent")"
state="$(printf '%s' "$record" | jq -r '.intent.state')"
[ "$state" = "accepted" ] || { echo "intent is $state, not accepted" >&2; exit 2; }
proposal_id="$(printf '%s' "$record" | jq -r '.intent.accepted_proposal_id')"
commit="$(printf '%s' "$record" | jq -r --arg id "$proposal_id" '.proposals[] | select(.proposal.id==$id) | .proposal.commit')"
fork_remote="$(printf '%s' "$record" | jq -r --arg id "$proposal_id" '.proposals[] | select(.proposal.id==$id) | .proposal.fork_remote')"
project_remote="$(printf '%s' "$record" | jq -r '.project.remote')"
title="$(printf '%s' "$record" | jq -r '.intent.title')"
seq="$(printf '%s' "$record" | jq -r '.intent.seq')"

with_token() { printf '%s' "$1" | sed "s#^https://#https://x:$2@#"; }

work="$(mktemp -d)"
trap 'rm -rf "$work"' EXIT
git -C "$work" init -q -b main
git -C "$work" fetch -q "$(with_token "$project_remote" "$ARMATURE_PROJECT_TOKEN")" main:refs/remotes/project/main || true
git -C "$work" fetch -q "$(with_token "$fork_remote" "$ARMATURE_FORK_TOKEN")" main:refs/remotes/fork/main
git -C "$work" merge-base --is-ancestor "$commit" refs/remotes/fork/main || {
  echo "accepted commit $commit is not on the fork's main; the fork moved on, file a new proposal" >&2; exit 4; }
if git -C "$work" rev-parse -q --verify refs/remotes/project/main >/dev/null; then
  git -C "$work" merge-base --is-ancestor refs/remotes/project/main "$commit" || {
    echo "project main is not an ancestor of $commit; rebase the fork and file a new proposal" >&2; exit 3; }
fi
git -C "$work" checkout -q "$commit"

export="$(api "/api/intent/$intent/export")"
dir="memoir/$(printf '%s' "$export" | jq -r '.dir')"
mkdir -p "$work/$dir"
printf '%s' "$export" | jq -r '.blueprint' > "$work/BLUEPRINT.md"
for f in intent.md exchanges.md proposals.md; do
  printf '%s' "$export" | jq -r --arg f "$f" '.files[$f]' > "$work/$dir/$f"
done
git -C "$work" add BLUEPRINT.md "$dir"
padded="$(printf '%04d' "$seq")"
git -C "$work" -c user.name="${GIT_AUTHOR_NAME:-armature}" -c user.email="${GIT_AUTHOR_EMAIL:-armature@localhost}" commit -q -m "Land intent $padded: $title."
git -C "$work" push -q "$(with_token "$project_remote" "$ARMATURE_PROJECT_TOKEN")" HEAD:refs/heads/main
if [ -n "${ARMATURE_MIRROR:-}" ]; then git -C "$work" push -q "$ARMATURE_MIRROR" HEAD:refs/heads/main; fi
echo "landed $(git -C "$work" rev-parse HEAD) for intent $padded"
```

```markdown
# Armature

A Git platform for one builder and their crew of agents, on Cloudflare
Workers and Artifacts.

We build stuff for ourselves and hope you like it too.

## What it is

You write what you want, in your words. The crew challenges it before anyone
writes code. Each agent works on its own fork and files proposals with
evidence. You read the diff, argue back, steer mid-flight, and decide what
lands. Everything said along the way is kept in the repository as the
project's memoir.

Strong software requires empathy.

## Who it is for

A builder who has the vision and reads code, and wants a crew that pushes
back. It is not for typing a sentence and receiving a product: the cockpit
shows diffs, not summaries.

Armature runs no model. The crew is whatever agents you run, on your
machine, talking to Armature over MCP. Their quality is yours.

## Words

- **Blueprint**: the vision and the intents in flight. What the crew follows.
- **Memoir**: the chapters that landed, under `memoir/`. What remains.
- **Pilot**: you. **Limb**: one agent on one fork. **Crew**: all of them.
- **Exchange**: anything said about an intent, in either direction.
- **Proposal**: a limb's commit, its touched paths, its evidence.

## Run it

1. `bun install`
2. `wrangler d1 create armature`, paste the id into `wrangler.jsonc`.
3. `wrangler queues create armature-events`, paste the queue id into
   `EVENTS_QUEUE_ID`.
4. `wrangler secret put PILOT_TOKEN` (any long string: your seat).
5. `wrangler secret put CF_API_TOKEN` (Queues Edit, Artifacts Read).
6. `wrangler d1 migrations apply armature --remote && wrangler deploy`
7. Open the Worker URL, enter your token, create a project. Push your code
   to the remote it shows. Connect the repo to Workers Builds in the
   dashboard if you want `main` to deploy.
8. Point your agents at `<worker-url>/mcp` with `Authorization: Bearer
   <token>`, and hand each one a file from `crew/`.
9. When you accept a proposal, run `bin/land <slug> <intent-id>` with the
   variables listed at the top of that script.

## Tests

`bun run test` runs the unit tests, the landing script test, and the
Workers tests.

## Licence

MIT. Copyright © 2026 Omnyist Productions, LLC.
```
