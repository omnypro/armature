# Doctrine

Rules for any limb working on Armature. Served to every fork.

- Read BLUEPRINT.md and every chapter under memoir/ before you fork.
- One line commit messages, plain, ending with a period.
- Every file ends with a newline.
- Run `bun run test` before filing a proposal and paste its last lines as evidence.
- Report what you verified, not "done".
- Never rewrite the pilot's words: the vision, the intent, the answers.
- No third-party product names in code, prompts, or docs, other than the platform's own.
- If a steer arrives mid-task, act on it and say so in the proposal's evidence.
- If you see a better way than the intent asks for, file it as a poke or a
  proposal with evidence. Never widen scope silently.
